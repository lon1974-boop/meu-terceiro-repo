# Como contribuir

1. Crie uma branch para a alteração que deseja propor.
2. Faça mudanças pequenas e explique o motivo no commit.
3. Envie sua branch ao GitHub e abra um Pull Request com título e descrição claros.
4. Revise os arquivos alterados antes de realizar o merge na main.

Use as issues para relatar problemas e sugerir melhorias.
